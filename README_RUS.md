# Abyssal Garden · Godot

[English README](README.md)

Порт Abyssal Garden на Godot .NET и C#. Это процедурный подводный мир с лесами ламинарии, затонувшим кораблём, мантами и объёмными световыми лучами. Порт основан на браузерном демо Максимилиана Дендуры (Noniv). [Оригинальный репозиторий](https://github.com/Noniv/abyssal-garden) · [Браузерная версия](https://noniv.github.io/abyssal-garden/)

## Запуск проекта

```powershell
git clone https://github.com/warlock-su/abyssal-garden-godot.git
cd abyssal-garden-godot
```

Откройте `project.godot` в Godot **4.8 beta 3 .NET** с установленным **SDK .NET 10** и нажмите **F5**. Проект проверен на Windows с Forward+ и Vulkan. [Загрузки Godot](https://godotengine.org/download/archive/4.8-beta3/)

Игра генерирует мир с выбранным уровнем детализации при запуске. В исходники и сборку Windows входит скомпилированная библиотека шейдеров. Для запуска достаточно файлов проекта или сборки.

В главном меню и меню паузы доступны русский и английский языки, пресеты размера окна и три уровня детализации. Рендер следует за видимой областью окна пиксель в пиксель. Для проверки пресетов из редактора запускайте игру в отдельном окне. [Встраивание окна игры в Godot](https://docs.godotengine.org/en/stable/tutorials/editor/game_embedding.html)

| Управление | Действие |
| --- | --- |
| Мышь, WASD | Обзор и плавание |
| E / Q, Shift | Подъём, спуск и ускорение |
| 1–6 | Переход к точке обзора |
| Esc, M, H | Пауза, переключение звука и подробная статистика |
| F, B | Полёт по маршруту и 60-секундный бенчмарк |

Для сборки под Windows x64 установите **шаблоны экспорта .NET** той же версии, что и редактор, и используйте пресет **Windows Desktop**. Запускайте `build/windows/AbyssalGarden.exe` рядом с его файлом PCK и каталогом данных .NET.

## Рендеринг и замеры

Godot `RenderingDevice` строит на GPU поле плотности морского дна. В фоновом потоке C# создаёт геометрию, коллизии, растительность, объекты, живность и объём освещения. Игра рисует инстансы, отбирает видимую геометрию и переключает LOD. Тени, вода с каустикой, объёмные лучи и bloom рисуются отдельными GPU-проходами. Исходные шейдеры WGSL компилируются в SPIR-V.

Первый вариант порта использовал данные, заранее экспортированные из браузерного генератора. В таблице указаны его **среднее / p99** в миллисекундах для одного 60-секундного маршрута на RTX 5090 при High. Chrome 157 использовал WebGPU, Godot 4.8 beta 3 использовал Vulkan. При 2560×1440 Godot рисовал буфер полного разрешения и выводил его в окно 1280×720.

| Разрешение рендера | Кадр Chrome | Кадр Godot | GPU Chrome | GPU Godot |
| --- | ---: | ---: | ---: | ---: |
| 1280×720 | 1,60 / 2,00 | 1,56 / 1,85 | 1,58 / 1,90 | 1,54 / 1,82 |
| 2560×1440 | 2,52 / 3,10 | 2,34 / 2,78 | 2,50 / 2,97 | 2,32 / 2,75 |

SSIM на шести контрольных кадрах при 1280×720 и High составил **0,991–0,997** с экспортированными данными и **0,643–0,803** с генерацией при запуске. Различия в вычислениях на GPU влияют на рельеф и на процедурное размещение растений и мелких объектов. [Команды для повторения замеров](README.md#rendering-and-benchmarks)

В отдельном сравнении сборок Windows Release на той же видеокарте, при High и 1280×720, генерация при запуске дала **1,64 / 1,96 мс** на кадр. Сборка с экспортированным миром в соседнем прогоне показала **1,63 / 1,86 мс**. Генерация мира на High заняла **1,7–2,1 с**, а размер PCK сократился с **240 до 1,0 МиБ**.

## Пересборка шейдеров

После изменений WGSL библиотеку шейдеров можно пересобрать с Node.js 24. Исходники шейдеров находятся в `source/`. [Исходная ревизия](https://github.com/Noniv/abyssal-garden/tree/a596354eff400d458bc2aeb9bdf5e0a9734b2bcf)

```powershell
npm install --prefix .godot/port-tools --no-audit --no-fund naga-wasi-cli@0.1.0
node tools/compile-shaders.mjs
```
